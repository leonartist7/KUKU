## Limitations and next task

These are fixture diagnostics, not production Core Web Vitals, p75/p95, physical Android results, leak proof or real realtime performance. Local gzip delivery is not Vercel CDN; no network latency shaping is applied. Brotli entries use quality4 estimates. Runner action spans include automation/CDP overhead; document elapsed/paint snapshots do not represent action latency or a complete CWV collection window. Heap counters fluctuate with GC and do not measure total memory. The chat fixture uses HTTP fallback after a synthetic unavailable WebSocket ticket.

Next dependency-ready P01 package: inventory actual icon-set imports and test direct imports without removing used sets; measure export/native changes against this checkpoint. Preserve glyph coverage, private-media authorization and latest-message anchoring. Production device/network budgets remain unaccepted. The live API cold probe in this rollout took37,850ms; free-service sleeping remains a separate hosting gate.
